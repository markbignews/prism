# Prism / 棱镜

[English](README.md)

Prism 是一个用于分析复杂关系与个人叙事的 AI 工具。它整理你描述的经历，寻找反复出现的模式，并比较不同解释。

**结论的强度，应该和证据的强度相匹配。**

## 分析原则

- **分清事实、用户解释和模型推断。** 用户描述了什么、用户如何理解、模型猜测了什么，需要分别对待。用户陈述的事件，也不等于经过独立核实的事实。
- **行为不等于动机。** 反复主动联系，可能来自习惯、实际需要、依赖或吸引。仅凭联系行为，不能替对方确定原因。
- **推断不会因重复而变成事实。** 模型之前的判断，再次引用时仍然是暂定判断。没有新证据，重复不应增加确定性。
- **消息时间不等于叙事时间。** 今天说的事，可能发生在几年前。只知道大致时期，就保留大致时期。
- **人物不是标签。** 可以结合具体证据讨论行为模式，但不能据此作人格定性或临床诊断。
- **Prism 可以不同意用户。** 它应检查反例、其他解释，以及是否把愿望当成了事实。有时信息就是不足以判断。
- **语气和判断是两个变量。** 理性、平衡、温情共用相同的证据标准。更温柔的表达，不应该变成更乐观的结论。

这些是设计约束，不是对模型准确性的保证。**不知道，就是不知道。** Prism 无法读心，也不能替用户决定一段关系到底是什么。

## 当前实现

Prism 是一个持续开发中的实验性 **SwiftUI 原生 macOS 应用**。当前源码包含：

- 按章节组织的对话、章节摘要与历史上下文检索。
- 人物和别名管理；归属不确定时由用户确认。
- 分开的叙事事件时间轴与情绪时间线。
- 证据关联、暂定分析记录，以及盲点与回答质量检查。
- 分别负责人物、章节归纳和用户画像的分析 worker。
- 共用判断规则的理性、平衡、温情三种回应方式。

对话和结构化记录使用 SQLite（`prism.sqlite3`）存储。来源消息关联和证据状态用于支持追溯，不代表每次解释都正确，也不代表每条陈述都经过独立核实。当前客户端为 SwiftUI，旧版 Tauri 和 Windows 运行说明已不适用于当前源码。

## 运行

要求：macOS 15 或更高版本，以及带 macOS SDK 的 Swift 6 工具链。仓库中的应用包面向 Apple Silicon。构建设置见 [Package.swift](Prism/swift%20version/Package.swift)。

在仓库根目录执行：

```sh
cd "Prism/swift version"
swift run -c release Prism
```

也可以打开仓库中的 `Prism/release/Prism-SwiftUI-macOS.app`。应用包可能落后于源码；上面的命令会构建当前源码，不会将应用安装到 `/Applications`。

首次启动时，在引导流程或设置中配置 API Key、端点和模型。当前默认使用 DeepSeek 端点与 `deepseek-flash`；Prism 不附带 API Key 或离线模型。

模型请求会将所需消息、主动添加的附件、相关分析或检索上下文发送给配置的服务商。请只上传你有权提供的信息。输出可能有遗漏或错误；Prism 不是心理治疗、诊断或急救服务。
