# Downloads

Published DMG, ZIP and checksums are available in [GitHub Releases](https://github.com/markbignews/prism/releases).

The latest published package is [v1.0.25](https://github.com/markbignews/prism/releases/tag/v1.0.25). It predates the newer changes on `main`; build from source to try those changes.

Generated `.app`, `.dmg`, `.zip` and checksum files are not committed. For a local build, run `python3 scripts/package_app.py` from the repository root; `--sync-release` optionally writes a second bundle here. Existing local release files were preserved under `.build/local-archive/releases-2026-11-07/` during the directory cleanup.
